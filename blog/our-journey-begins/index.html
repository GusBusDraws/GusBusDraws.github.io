Our Journey Begins

Today Kaila and I begin our trip to Southeast Asia! We are flying into Hanoi, Vietnam first, although to get there is its own journey. We start with a two hour flight from Denver International Airport to LAX where we'll have a 2.5 hour layover. The next one from LAX to Seoul, South Korea is the big one at 13 hours. After another 1.5 hour layover, we have our final flight to Hanoi!

Writing HTML on an iPad

I spent the first flight trying to get used to writing HTML on my iPad! I found an apps called Working Copy to help me out! The app connected to my GitHub account and has a built in text editor that lets me clone repos, edit files, and even push changes. Since my website is hosted with GitHub Pages, this means I can update my website. That's how I started this blog! The only catch is that the GitHub connectivity requires the Pro version of the account, which is a one-time payment of $40. I'm using the free 10 day trial to decide if I want to continue using this app. Since I haven't found an alternative and the experience so far has been smooth, I'm considering it! Feels good at least that it would be supporting a single developer.
