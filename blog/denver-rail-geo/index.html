Denver Rail Map vs Real Geography

Inspiration

I have seen some cool visualizations where people compare the simplified maps used to navigate a transit system with the real geography of the lines. I have seen this done for big subway systems like the DC Metro and the London Tube, but I wasn't able to find one for Denver's small light rail system. The system itself is definitely not anything special, but Denver being my home, I really wanted to see this! So I decided I'd make it myself.

Getting the points from the image

To make this work, I'll need location data for the rail lines on the map as well as the real geographic locations. RTD, the public transportation operator for the Denver Metro, provides the geospatial data for the real geography on the lines on their website, but not any kind of location data for the transit map, which makes sense because there's no reason a regular person ever need that. They do provide a rail system map on their website, but it's a raster image which means I can't easily pull the location line data from it.

I see two options to move forward. The first option would be to trace the lines on the map in a vector graphics editor like InkScape and extracting the position of the points from the vector obects I would create in the process. This would probably be the more sane thing to do. However, the second option involves image processing, and to me that seemed like a more interesting challenge. If I can get an image processing routine working to extract the coordinates of each line, then it may also have the added benefit of allowing me to apply it to other rail maps.

Moving forward with the image processing challenge, the first thing I wanted to try was trying to identify the lines based on color. Even in HSV (hue, saturation, value) space, this proved too difficult since many of the lines have similar colors to one another. I decided I would simplify the task by manually placing points on the map to sample the color of each line.

Before using these colors to select the lines from the map, I needed to clean the map by removing some of the other features that have the same colors. This included the legend (where I originally chose the colors) and rail line labels besides each line. I removed these features by manually selecting rows and columns of pixels in the map image and setting all those selected pixels to white.

After cleaning up the image, I was able to use the color I chose for each line (represented by a set of red, green, and blue or RGB values), to match these values with the pixels of the system map to find the rest of each line. However, when I first tried this, it became that each line was not consistently a single set of RGB values. In order to select the majority of each line, I needed to allow for a certain amount of tolerance in each RGB value.

After finding a good tolerance, I was able to select each line and segment it from the rest of the image.
